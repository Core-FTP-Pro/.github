## What Is Core FTP Pro

Core FTP Pro is a file transfer client for servers you may use. Core FTP Pro site manager holds the addresses. Core FTP Pro sftp session is the connection when the host offers a protected path. Students handing in work, or a small office exchanging a project folder, can keep those sites named instead of retyping them.

Core FTP Pro file queue helps when more than one file should move. Core FTP Pro folder sync helps when a whole directory should match, such as a chapter folder before class. Core FTP Pro bookmark opens the remote directory you always need. None of this is for hosts that did not give you an account.

Add one site in Core FTP Pro site manager, connect with Core FTP Pro sftp session, and send one file through Core FTP Pro file queue. Save Core FTP Pro bookmark. Try Core FTP Pro folder sync on a copy of a small folder before you point it at anything important.
